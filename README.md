# Brev.ly - Server

Encurtador de URLs. Projeto desenvolvido para a Faculdade de Tecnologia Rocketseat.

## Como rodar

```bash
pnpm install
pnpm dev
```

Isso sobe os serviços via Docker, roda as migrations e inicia o servidor com hot reload.

## Testes

```bash
pnpm test
```

## Build

```bash
pnpm build
pnpm start
```
